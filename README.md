## INSTALL

SNEK RENAISSANCE is an installable Progressive Web App.

Use **INSTALL** above to open the game in installation mode. When the browser exposes its native PWA install prompt, the page enables the install action and delegates to that native flow. If programmatic installation is unavailable, the page shows the appropriate browser/manual fallback instead of presenting a dead control.

Once installed and cached, SNEK RENAISSANCE can relaunch as a standalone application and continue to support offline startup.

---

## FORK

Use **FORK** above to open GitHub's fork flow for this repository, or clone it directly:

```bash
git clone https://github.com/Liquifinity/snekrenaissance.git
cd snekrenaissance
npm install
npm run dev
```

Forks are deployment-ready: GitHub Pages automatically adapts to the repository name.
